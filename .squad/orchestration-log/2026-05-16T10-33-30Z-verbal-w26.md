## Plain-Language Summary

Two intertwined bugs broke the "create issue → auto-run" end-to-end loop. Bug A: auto-assignment keyword router had a word-length filter of `> 3` chars, allowing generic 4-letter words like `"type"` and `"icon"` in Fenster's pattern to match almost any issue, routing unrelated work to Fenster instead of leaving it unassigned. Fix: raised threshold to `> 4` (5+ chars), removing spurious matches. Also deterministically ordered agent fallbacks (ORDER BY name) and removed arbitrary picks in MCP `run_agent`. Bug B: no sweep existed to pick up To Do items that arrived without a routing match, so they sat dormant. Fix: added new `pickupTodosSweep` (10s interval) that scans To Do items without active runs, applies Tier-2 keyword scoring, and falls back to least-loaded agent distribution. Verified with 10 new test cases (7 Bug A + 3 Bug B); all 434 server tests pass.

## Canonical Assignment Rules (W26 finalized)

| Scenario | Behavior |
|---|---|
| Issue + matching label rule | Tier-1 routes immediately |
| Issue + matching keyword (≥5 chars) | Tier-1 routes immediately |
| Issue + no routing match | Starts unassigned; no run created |
