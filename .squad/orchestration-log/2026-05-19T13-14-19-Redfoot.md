#### Configuration Recipes

**1. Squadboard (Local PGlite with optional PostgreSQL override)**
```bash
# Default: filesystem storage
SQUADBOARD_SQUAD_STORAGE_PROVIDER=fs

# Local PGlite database
SQUADBOARD_SQUAD_STORAGE_PROVIDER=postgresql

# Hosted PostgreSQL (when DATABASE_URL is set)
SQUADBOARD_SQUAD_STORAGE_PROVIDER=postgresql
DATABASE_URL=postgresql://...
```

**2. Squad CLI Direct DB Mode (Shared PostgreSQL)**
```bash
# Squad CLI with PostgreSQL provider
SQUADBOARD_SQUAD_STORAGE_PROVIDER=postgresql
DATABASE_URL=postgresql://... # same as Squadboard
SQUAD_STORAGE_SCOPE=my-project-uuid
```

**3. Copilot CLI Direct DB Mode (Shared PostgreSQL)**
```bash
# Copilot with PostgreSQL provider pointed at shared DB
SQUADBOARD_SQUAD_STORAGE_PROVIDER=postgresql
DATABASE_URL=postgresql://... # same as Squadboard
```

**4. Stock Copilot CLI + MCP Broker Mode**
```bash
# Copilot uses Squadboard MCP server (no direct DB access)
SQUADBOARD_MCP_SERVER=http://localhost:3000
# Squadboard handles all storage operations
```

#### Warnings Added
- Local PGlite has no cross-process SQL endpoint; direct database sharing requires hosted PostgreSQL
- Shared-state requires all runtimes use compatible provider at same database + scope
- Squadboard broker (MCP) is the safe default for external tool integration
