## Delivery

**Problem:** Heartbeat events emitted to shared project EventBus with synthetic `projectId = '__heartbeat__'`. Ceremony dispatcher listened to all events and passed `'__heartbeat__'` to Postgres UUID column → `22P02` type error every 5 seconds. Error count: 2 per tick across all sweeps.

**Solution — Option A:** Separate `'heartbeat'` EventEmitter channel (not `'event'` channel):
```ts
emitHeartbeatEvent() → eventBus.emit('heartbeat', {...})
eventBus.onHeartbeat(handler) // New helper
```

**Why Option A:** Heartbeat is server-wide infrastructure, not project-scoped. Sharing the bus violates the existing `'event'` channel contract (every payload must have valid UUID projectId).

**Dispatcher Guards:**
1. **Early type guard:** if `event.type.startsWith('heartbeat.')` → return (belt-and-suspenders)
2. **UUID guard in `findMatchingCeremonies()`:** Validates projectId against UUID regex; returns [] + debug log if non-UUID

**Result:** UUID errors → 0 per tick. No regression in ceremonies or other subsystems.
