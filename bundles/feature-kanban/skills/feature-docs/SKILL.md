## Documentation checklist

- Overview and when to use the feature
- Prerequisites
- Setup or usage steps
- Examples
- Limitations and known behaviors
- Troubleshooting
- Related tasks or next steps

## Quality bar

A new user should understand whether the feature applies to them, how to start, how to verify success, and where to go next.
