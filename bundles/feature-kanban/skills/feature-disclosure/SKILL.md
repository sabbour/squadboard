## Structure

1. Feature name and status if relevant
2. One or two sentences on customer value
3. What's new bullets
4. Availability, prerequisites, or limitations
5. Link or next step

## Style

Lead with what users can now do. Use plain language and active voice. Avoid internal ticket numbers, implementation detail, unsupported commitments, and marketing superlatives.
