# Private Squadboard App Candidates

Local staging area for app packages intended for a future private repo, not the public `@sabbour/squadboard-apps` catalog.

These folders are intentionally outside `squadboard-apps/`, so the development server does not list them on the public Squadboard Apps browse surface.
