Start here if you are setting up Squadboard for the first time or evaluating the pre-alpha workflow with the Spark project. Read the pages in order if you want one continuous path: install locally, finish the quickstart, then continue into the Spark tutorials.

The tutorials follow the same operating flow throughout: create Spark, review the team, delegate cards by moving them to Ready, approve the work that needs judgment, and watch the board, ceremonies, and MCP surfaces stay in sync.
