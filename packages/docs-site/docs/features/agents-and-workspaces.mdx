## Capability summary

| Capability | What it gives you |
| --- | --- |
| Project agents | Repository-owned roles, charters, expertise, and origin metadata. |
| Consult | Proposal-driven brainstorming with project agents or raw models before state changes. |
| Spawn context | Charter, workspace, requester, history, skills, MCP/tool context, and validation expectations. |
| Workspace isolation | Scratch, directory, and worktree strategies for parallel runs with auditable cleanup metadata. |

For operating details, use [Agents, skills, tools, and MCP servers](../user-guide/agents-skills.mdx), [MCP integration](../user-guide/mcp.mdx), and [Squad integration](../user-guide/squad-integration.mdx).
