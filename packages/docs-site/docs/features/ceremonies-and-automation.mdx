## Capability summary

| Capability | What it gives you |
| --- | --- |
| Ceremony templates | Repeatable project rituals that can be reviewed before deployment. |
| Triggered workflows | Manual, scheduled, GitHub-event, and agent-signal entry points. |
| Lifecycle automation | Scribe close-out, run recovery, review timeouts, and Ready pickup happen through server loops. |
| Ralph-equivalent monitor | Opt-in project monitor that looks at Ready work before GitHub follow-up signals. |
| Visual designer | Mainstream linear and fan-out workflow editing, with YAML review for advanced graphs. |

For operating details, use [Ceremonies and workflows](../user-guide/ceremonies-workflows.md), [Built-in templates and defaults](../user-guide/built-ins.mdx), and [Coordinator loops](../user-guide/coordinator-loops.mdx).
