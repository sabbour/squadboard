# Squadboard Apps

Public-safe example Squadboard Apps. Each folder contains:

- `squadapp.json` — browse metadata and package classification (`kind: "squadboard-app"`)
- `squad-bundle.json` — installable project bundle consumed by Squadboard
- `README.md` — short install/use notes

Current examples:

- `squad-doc-review` — review Squad documentation changes.
- `squad-issues-router` — operating model for scheduled intake and triage of Squad GitHub Issues; reusable importer backend is still required.
